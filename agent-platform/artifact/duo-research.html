Claude 확인 중 Gemini 확인 중

Claude가 이끌고 Gemini가 검색합니다

Claude는 이 claude.ai 계정에서 바로 돌아가고, Gemini는 Google 검색으로 근거를 모아 옵니다. 출처로 확인되지 않은 내용은 [미확인]으로 남깁니다.

  1. Claude질문을 나눠 검색 과제 배정
  2. GeminiGoogle 검색으로 과제별 조사
  3. Claude → Gemini약한 주장을 골라 재검색 요청
  4. Claude출처 번호를 달아 답변·결과물 작성
Gemini 연결 방법 (최초 1회)
  1. 저장소의 agent-platform/gemini-mcp/server.mjs를 PC에 받습니다. Node.js 18 이상이 필요합니다.
  2. Claude 데스크톱 앱 설정의 개발자 메뉴에서 MCP 설정 파일(claude_desktop_config.json)을 열고 아래 항목을 추가합니다.
{
  "mcpServers": {
    "gemini": {
      "command": "node",
      "args": ["/경로/agent-platform/gemini-mcp/server.mjs"],
      "env": { "GEMINI_API_KEY": "여기에_키", "GEMINI_MODEL": "gemini-2.5-flash" }
    }
  }
}
  1. 앱을 다시 시작하고, 이 페이지를 Claude 데스크톱 앱에서 엽니다. 웹 브라우저에서는 Gemini 없이 Claude만 동작합니다.
